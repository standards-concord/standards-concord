# Profile pictures for demo accounts

Generated by [`scripts/generate-avatars.mjs`](../../../../scripts/generate-avatars.mjs) (`pnpm avatars`) and committed, so the demo works offline and never asks a third-party service for an image.

- `personas/<key>.svg`: one per simulated working-group member.
- `demo/NN.svg`: a pool the server hands out to alpha testers' demo accounts by a hash of the account id.
